# 🎵 Spotify Clone App

A simple frontend **Spotify UI clone** built using **HTML**, **CSS**, and **JavaScript**.  
This project replicates the main interface of Spotify, including the sidebar, music player, and trending sections.

## 🚀 Features

✅ Responsive sidebar with navigation links (Home, Search, Library)  
✅ Sticky navigation bar for main content  
✅ Card-based layout for featured playlists, charts, and trending tracks  
✅ Fixed bottom music player with album details, player controls, and volume control  
✅ Hover effects and modern Spotify-like styling  
✅ FontAwesome icons integration for UI components

```

/assets          → image & icon assets used in the UI
index.html       → main HTML file
style.css        → stylesheet
script.js        → JavaScript (optional, if adding interactivity)
README.md        → project documentation

````

## 📦 Installation

1. Clone the repository:
2. Open the folder in your code editor.
3. Simply open `index.html` in your browser to view the app.

No additional dependencies required — runs purely on HTML, CSS, and JS.

## ✨ How to Use

* Click on navigation links to explore the sidebar.
* View trending playlists and charts in the main content area.
* Use the music player controls (non-functional placeholders) at the bottom.

> **Note:** This is a static frontend clone — no backend or actual music streaming is included.
